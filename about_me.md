## Selected Projects

### Insurance Pricing and Risk Modelling

Developed and compared machine-learning models for insurance pricing and risk analysis, using approaches including GLM, Ridge, Gradient Boosting, LightGBM, KNN, and XGBoost. The workflow included data preparation, feature engineering, model evaluation, hyperparameter tuning, and cross-validation to compare candidate models and select a suitable final model. Worked with pricing-related outputs and collaborated with actuarial and underwriting stakeholders to support premium and risk decisions.

**Tools and methods:** Python, SQL, scikit-learn, LightGBM, XGBoost, Azure Databricks, model comparison, cross-validation, hyperparameter tuning.

### Insurance Risk Classification and Model Monitoring

Worked on insurance risk-classification workflows using structured policy and customer data. The work involved data-quality checks, handling missing values, model evaluation, and considering model performance over time, including potential data or model drift. Explainability methods such as SHAP can help make model outputs easier to interpret for business and technical stakeholders where used in the workflow.

**Tools and methods:** Python, SQL, scikit-learn, XGBoost, PySpark, Azure Databricks, MLflow, data validation and model monitoring.

### Vox Sentiment — Speech Intelligence for Call Centre Conversations

Developed a speech analytics application to transcribe conversations, identify speakers, analyse sentiment, and generate summaries. The project used Faster-Whisper, Pyannote, Hugging Face Transformers, Streamlit, and MongoDB. Evaluation included Word Error Rate (WER), Diarisation Error Rate (DER), and ROUGE-L.

### Insurance Claim Prediction

Built a machine-learning web application using Python and XGBoost to demonstrate an end-to-end prediction workflow, from model development to a web interface for submitting inputs and viewing predictions.
